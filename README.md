# BookImpl
Pet Project

Цель практического задания
Освоить профессиональные подходы к проектированию приложений, работающих с базами данных:

Применение паттерна Data Access Object (DAO) для разделения слоя данных и бизнес-логики
Настройка и использование connection pool для эффективного управления соединениями
Создание многослойной архитектуры приложения
Внедрение dependency injection для улучшения тестируемости и гибкости
Организация кода в соответствии с принципами SOLID
Этот этап преобразует наше приложение из учебного примера в production-ready архитектуру.

Архитектура DAO:

Все интерфейсы DAO корректно определены с полным набором CRUD операций
JDBC реализации следуют контрактам интерфейсов
Используется dependency injection через конструкторы
Отсутствует прямая зависимость между сервисами и конкретными реализациями DAO
Connection Pool:

HikariCP правильно настроен с оптимальными параметрами
Размер пула соответствует требованиям приложения
Настроены таймауты соединений и валидация
Пул корректно используется всеми DAO классами
Service слой:

Бизнес-логика полностью инкапсулирована в сервисах
Сервисы не содержат SQL кода или деталей работы с БД
Транзакционность управляется на уровне сервисов
Сервисы возвращают DTO вместо сущностей домена
Управление ресурсами:

Все DAO используют один экземпляр DataSource
Соединения правильно возвращаются в пул
Отсутствуют утечки соединений
Используется try-with-resources для автоматического управления ресурсами
Обработка ошибок:

SQLException преобразуется в доменные исключения
Исключения содержат информативные сообщения
Ошибки логируются для последующего анализа
Пользовательский интерфейс защищен от технических деталей ошибок
Качество кода:

Соблюдение принципов SOLID
Низкая связность между компонентами
Высокая связность внутри компонентов
Код хорошо документирован и протестирован
Отсутствует дублирование логики

Тестируемость:
Архитектура позволяет легко мокировать зависимости
Сервисы могут тестироваться без реальной базы данных
Использование интерфейсов позволяет подменять реализации
